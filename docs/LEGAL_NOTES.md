# Legal notes (Master Plan Task 0.9)

## Media downloads (yt-dlp)

`download_media` downloads audio/video via `yt-dlp`. Downloading copyrighted
content may violate your country's copyright law or a platform's Terms of
Service. **Use it only for content you own, that is freely licensed, or that
you have explicit permission to download.** This is entirely your
responsibility; the JARVIS authors are not liable for misuse.

## The name "JARVIS"

"JARVIS" is famously the name of a Marvel/Disney character. Using it for a
personal, non-commercial project is generally tolerated, but **do not use it
as a public product/brand name** without proper clearance — pick an original
name before any public release (see master-plan Task 8.8).

*We are not lawyers. If you need legal certainty, consult one.*
