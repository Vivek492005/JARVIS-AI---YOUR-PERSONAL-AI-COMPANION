05 — INITIALIZE

Bring it
online.

Four steps from a repository to your first voice command. Windows 10/11, Python 3.10+.

Open the repository ↗

Clone the repository

$ git clone https://github.com/Vivek492005/JARVIS-AI---YOUR-PERSONAL-AI-COMPANION.git

Run the installer

Creates the virtual environment and installs every dependency.

$ cd JARVIS-AI---YOUR-PERSONAL-AI-COMPANION
$ .\install.bat

Add your keys

Create a .env file next to main.py. The first-run dialog can also collect these for you.

# .env
HUGGINGFACE_API_KEY=hf_...
DEEPSEEK_API_KEY=sk-...
RUMIK_API_KEY=...

Launch JARVIS

Say the wake word and talk — English, Hindi, or Hinglish.

$ .\Launch_JARVIS.bat
