04—INITIALIZE

Bring it
online.

Four clean steps from a repository to your first voice command.

Clone the repository

$ git clone https://github.com/your-username/Saarthi.git
$ cd Saarthi

Prepare the environment

$ .\.venv\Scripts\activate
$ pip install -r requirements.txt

Configure your keys

Add HuggingFace, DeepSeek, and Rumik credentials to .env.

Launch Saarthi

$ .\.venv\Scripts\python main.py
